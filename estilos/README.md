# Estilos de guion y producción

Cada estilo tiene un `.json` (lo lee el programa: selector de estilo, prompts de ideas/guion/escenas) y un `.md` (guía para humanos con ejemplo de guion).

- `vectorial_explicativo` — animaciones vectoriales de ciencia cotidiana (referencias: pescado, carne cruda, piernas, avión, nicotina).
- `mapa_ruta` — mapas satelitales con ruta y cámara que sigue (referencias: Karl Bushby, GEOallday, Mundo_Explora).

**Estilos propios (privados):** pon `.json` en `cache/estilos_privados/`; el programa los lista junto a los demás y el actualizador nunca los toca ni los sube.

Esta carpeta guarda *lo aprendido* de las referencias (estructura, ritmo, recursos), no los videos de otros creadores.
