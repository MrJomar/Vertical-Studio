# Efectos de sonido disponibles

Usa la etiqueta en `"sfx"` de la escena (ej.: `"sfx": ["impacto@0.8"]`).

- **click** — aparece un texto, un pin o un detalle pequeño (1 archivo, 0.021 s, agudo)
- **ding** — acierto, dato clave, aviso (1 archivo, 1.0 s, medio)
- **impacto** — susto, dato fuerte, golpe dramático (1 archivo, 1.1 s, grave)
- **pop** — aparece una pieza o elemento (1 archivo, 0.122 s, grave)
- **splash** — agua, líquido, golpe de color (1 archivo, 0.578 s, agudo)
- **subida** — tensión que crece antes de una revelación (1 archivo, 1.108 s, agudo)
- **tic** — reloj, cuenta atrás, tensión (1 archivo, 0.045 s, medio)
- **whoosh** — transición entre escenas, cámara que se mueve rápido (1 archivo, 0.567 s, agudo)
- **whoosh_corto** — cambios de plano rápidos, elementos que cruzan la pantalla (1 archivo, 0.29 s, agudo)
